Como funciona

  1. ColetaUm script em Python busca manchetes no Google News para 9 temas. A própria busca vira o rótulo de cada notícia.
  2. Texto → númerosCada manchete vira um vetor TF-IDF com palavras e pares de palavras.
  3. TreinoUma Regressão Logística (scikit-learn) aprende o peso de cada palavra para cada tema.
  4. No navegadorOs pesos são exportados em JSON e este site refaz a conta em JavaScript, sem servidor.
  5. Toda semanaO GitHub Actions coleta notícias novas, retreina e publica o modelo atualizado.
